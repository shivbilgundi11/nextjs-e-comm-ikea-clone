# IKEA Clone E-Commerce Web App

Welcome to the IKEA Clone E-Commerce Web App! This project is a fully functional e-commerce application inspired by IKEA, designed to provide a seamless shopping experience. Built using modern web technologies such as Next.js, TypeScript, and Tailwind CSS, this application allows users to explore and purchase a wide range of furniture, decorations, and lighting products.

## Live Demo

Experience the application live: [IKEA Clone Demo](https://shiv-ikea-clone.vercel.app/)

## Key Features

- **Product Listings**: Browse through a variety of products categorized for easy navigation.
- **Shopping Cart**: Add or remove products from your cart effortlessly.
- **Authentication**: Secure user authentication for personalized experiences.
- **Wishlist**: Sign in to save your favorite products to your wishlist.
- **Product Details**: Detailed product pages with all necessary information.
- **Multi-Page Application**: Organized structure for a smooth user journey.
- **Responsive Design**: Fully optimized for all devices, ensuring a great user experience on mobile, tablet, and desktop.

## Installation

Follow these steps to set up the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/shivbilgundi11/nextjs-e-comm-ikea-clone.git my-project
   ```

2. Navigate to the project directory:

   ```bash
   cd my-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
